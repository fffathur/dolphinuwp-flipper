# Flipper 3 - default theme intended for the next release of Dolphin UWP

[Latest version of Dolphin UWP on GitHub](https://github.com/SternXD/dolphin)

## System Requirements

Recommended: Xbox Series S or Xbox Series X

Minimum: Xbox One, Xbox One S, or Xbox One X (expect games to not run well on these platforms) 

## Note

Flipper 3 is unfinished and incompatible with current versions of Dolphin UWP (without reworking it manually). It is highly subject to change at this time.
